# Pyctures Docs

Pyctures is for making 2D and 3D graphics and games in Python, and for enjoying it: you write a short program and it draws in a web browser. It is for any age and any level, a first program or a thousandth, and is designed to bring the joy back into programming. Plain drawing functions get you started, with the web's 2D canvas for everything else in 2D, and three.js for 3D: the full set of JavaScript graphics functions, from Python.

Start here: [Getting started](getting-started.md).

The same shape of program in JavaScript: [pictures.js](https://www.circuitry.dev/pictures), the sibling library, draws from a plain `.js` file with no HTML to write.

These pages are adapted from the Pyctures help in [Circuitry Studio](https://www.circuitry.dev), where the same scenes run with a live preview beside the code, on phones, iPad, the web and desktop, with no subscription needed: [circuitry.dev/docs/pyctures](https://www.circuitry.dev/docs/pyctures).
