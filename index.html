PycturesPython 2D and 3D graphics, drawn in your web browser

Every scene below is a short Python program. Click one and it runs live in your browser, with its code beside it. Python gets the web's 2D canvas and three.js 3D, with the names JavaScript uses.

pip install pycturesStar on GitHubDocs
